HANUAI ML ASSESSMENT SUBMISSION

Files:
- task1_scraping_sentiment.ipynb: Playwright + BeautifulSoup scraping framework and VADER sentiment baseline.
- task1_output_schema.csv: empty schema only; no fabricated review data.
- task1_technical_report.docx: method, compliance and reporting framework.
- task2_eda_text_mining.ipynb: EDA, data quality checks, keyword entity tags, issue categories and TF-IDF/K-Means.
- task2_tagged_dataset.csv: supplied 1,000-record dataset enriched with tags and exploratory issue categories.
- task2_stakeholder_report.docx: data quality findings, approach, business interpretation and limitations.

Important:
1. Run notebooks from a folder containing the source CSV.
2. Task 1 requires setting a real Best Buy Canada product URL and inspecting/updating selectors against the current public page.
3. Task 1 is not represented as completed: no real reviews were scraped in this environment.
4. Task 2 tags are heuristic and must be validated by a domain expert before operational use.
